## Overview

Acurast is a decentralized, verifiable compute network designed to provide infrastructure for AI agents and general secure applications. Instead of relying on traditional centralized data centers, the platform utilizes the unused processing power of global smartphone hardware. By leveraging the built-in hardware-secured enclaves found in modern mobile devices, Acurast enables developers to run distributed, confidential, and tamper-proof computing workloads.

The architecture focuses on scalability and data privacy, allowing applications to execute tasks securely across a decentralized footprint.
